# 🚀 SaaS Landing Page Template

A **responsive, dark-mode enabled, modern SaaS landing page** built with **Tailwind CSS**. Perfect for startups, SaaS products, mobile/web apps, or any tech business looking for a clean and professional marketing page.

![Preview of SaaS landing page](images/hero-image.jpg)

---

## ✨ Features

- ✅ Clean, modern UI  
- ✅ Fully responsive (mobile/tablet/desktop)  
- 🌙 Dark mode toggle  
- 📊 Features, pricing, use case, and FAQ sections  
- 📷 Product screenshots gallery  
- 🎨 Built with Tailwind CSS  
- ⚡ Smooth scroll & animations using [AOS.js](https://michalsnik.github.io/aos/)  
- 🔒 No external dependencies except CDNs  

---

## 🛠 Tech Stack

- HTML5  
- Tailwind CSS  
- AOS.js  
- Font Awesome

## 📦 Getting Started

1. **Download or Clone the Repo**
2. **Customize**
   - Replace text in `index.html` with your product info.
   - Replace image files in the `/images` folder.
3. **Preview Locally**
   - Open `index.html` in your browser.
4. **Deploy**
   - Use Netlify, Vercel, GitHub Pages, or any static hosting provider.

---

## 🧑‍🎨 Customization Guide

- Logo: `images/logo.png`  
- Hero Background: `images/hero-image.jpg`  
- Screenshots: `images/image1.png`, `image2.png`, etc.  
- Update text/content in `index.html` directly  
- Tailwind-based layout with dark mode support
